## 1. 安装与启动

### macOS

1. 双击 `.dmg` 文件，将 PDF Seeker 拖入 Applications 文件夹
2. 首次打开如果提示"已损坏"，打开终端执行：
   ```bash
   xattr -c /Applications/PDF_Seeker.app
   ```
3. 重新双击打开即可

### Windows

1. 双击 `.msi` 安装包，按提示完成安装
2. 从开始菜单或桌面快捷方式启动

### Linux

1. `.deb` 包：`sudo dpkg -i pdf-seeker_*.deb`
2. `.AppImage`：下载后 `chmod +x` 赋予执行权限，双击运行

## 3. 打开文件

PDF Seeker 支持三种方式打开 PDF 文件：

### 方式一：工具栏按钮
点击工具栏的「打开文件」按钮，在弹出的文件选择器中选择 PDF 文件。

### 方式二：首页按钮
在首页点击「打开 PDF 文件」按钮。

### 方式三：拖放
将 PDF 文件直接拖拽到首页或查看器的窗口中。

> 打开文件后，文件路径会显示在工具栏中，部分工具会自动识别已打开的文件。

## 4. PDF 查看器

点击侧边栏的「查看器」进入 PDF 阅读模式。

### 基本操作

| 操作 | 方法 |
|------|------|
| 翻页 | 鼠标滚轮、方向键、PageUp/Down |
| 跳转页码 | 在页码输入框中输入目标页码 |
| 缩放 | 触控板捏合、`Ctrl + =/-`、工具栏缩放按钮 |
| 适应宽度 | 点击「适应宽度」按钮 |
| 适应页面 | 点击「适应页面」按钮 |
| 全屏 | 按 `F11` 或点击全屏按钮 |

### 暗色模式

在设置中切换主题为「深色」，或在工具栏点击主题切换按钮。暗色模式下 PDF 页面会叠加半透明暗色层，不会反转水印和签名颜色。

## 5. 工具箱总览

点击侧边栏的「工具箱」进入工具选择页面。当前提供 18 个工具：

| 分类 | 工具 |
|------|------|
| **页面操作** | 合并、拆分、旋转、删除页面、提取页面、页面排序、插入页面（待真实 PDF 验收） |
| **文档增强** | 压缩、水印、签署 |
| **格式转换** | 图片转 PDF、PDF 转图片、PDF 转文本 |
| **内容提取** | 文本提取、OCR 识别、表格提取 |
| **页面编辑** | 添加文字、矩形、高亮 |
| **批量处理** | 批量处理 |

每个工具卡片下方有简短描述，帮助你快速找到需要的工具。

> **当前安全状态**：本构建可读取 PDF 的加密状态，但未提供密码加密、解密或批量加密功能。

## 6. 页面操作

### 合并 PDF

1. 进入工具箱 → 点击「合并」
2. 点击「选择文件」添加多个 PDF 文件
3. 通过拖拽调整文件顺序
4. 点击「合并并保存」，选择输出路径

### 拆分 PDF

1. 进入工具箱 → 点击「拆分」
2. 打开一个 PDF 文件
3. 输入页码范围（如 `1-3, 5, 7-10`）
4. 点击「拆分并保存」

### 旋转页面

1. 进入工具箱 → 点击「旋转」
2. 打开 PDF 文件，缩略图网格显示所有页面
3. 选择旋转角度（90°/180°/270°）
4. 在缩略图上点击需要旋转的页面
5. 点击「旋转并保存」

### 删除页面

1. 进入工具箱 → 点击「删除页面」
2. 打开 PDF 文件
3. 在缩略图上点击需要删除的页面（被选中的页面会标红）
4. 点击「删除选中页面并保存」

### 提取页面

1. 进入工具箱 → 点击「提取页面」
2. 打开 PDF 文件
3. 在缩略图上点击需要提取的页面（被选中的页面会标绿）
4. 点击「提取选中页面并保存」

### 页面排序

1. 进入工具箱 → 点击「页面排序」
2. 打开 PDF 文件
3. **拖拽**缩略图调整页面顺序
4. 当前排列顺序会实时显示在上方
5. 点击「排序并保存」

### 插入页面（待端到端验收）

1. 打开目标 PDF 后，在页面工具中点击「插入页面」
2. 选择要插入的源 PDF
3. 输入插入位置；`0` 表示插入到第一页之前
4. 选择输出路径并执行保存

> 工具栏、对话框与 Rust command 已接入；在真实 PDF 样本完成“保存后重新打开”验收前，请保留原文件并核对输出结果。

## 7. 文件转换

### 图片转 PDF

1. 进入工具箱 → 点击「图片转 PDF」
2. 点击「选择图片」添加多张 JPG/PNG 图片
3. 通过拖拽调整图片顺序
4. 点击「转换并保存」

### PDF 转图片

1. 进入工具箱 → 点击「PDF 转图片」
2. 打开 PDF 文件
3. 设置 DPI（默认 150）
4. 点击「导出图片」，选择输出文件夹
5. 每页会导出为一个独立的 PNG 文件

### PDF 转文本

1. 进入工具箱 → 点击「PDF 转文本」
2. 打开 PDF 文件
3. 点击「提取文本」
4. 提取完成后可复制或导出为 `.txt` 文件

## 8. 内容提取

### 文本提取

使用 pdfjs-dist 内置引擎直接提取 PDF 中的文字内容，无需联网。

### OCR 识别

如果 PDF 是扫描件或图片 PDF，文本提取可能无法获取文字。OCR 使用 PP-OCRv5 模型与 MNN 推理引擎；首次使用前需要在设置中下载或导入模型。

> OCR 识别准确率取决于扫描质量、所选语言模型与页面排版。模型下载或 S3 操作需要网络，其余本地 PDF 功能可离线运行。

### 表格提取

详见 [第 10 节](#10-表格提取)。

## 9. 编辑工具

PDF Seeker 提供添加文字、绘制矩形、添加高亮等页面级编辑交互。这些操作会先以叠加层形式预览。

> **重要**：当前编辑写入流程尚未通过真实 PDF 的端到端验收；“Save All”会尝试生成新文件，但输出 PDF 的可打开性和视觉结果不能视为已保证。请始终保留原文件。

### 共同特性

- **大画布预览**：接近原始尺寸的页面预览，所见即所得
- **鼠标拖拽选区**：在预览画布上拖拽可直接设定位置和大小
- **撤销/重做**：`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做
- **批量保存（待验收）**：所有编辑操作暂存在内存中；“Save All”会尝试一次性应用到新文件，必须人工重新打开并核对输出

### 添加文字

1. 进入工具箱 → 点击「添加文字」
2. 打开 PDF 文件
3. 在左侧面板设置：
   - 输入要添加的文字内容
   - 选择目标页码
   - 设置字体大小和颜色
   - 设置 X/Y 坐标（或使用鼠标在预览中点击定位）
4. 点击「Add」将操作加入历史
5. 预览画布会实时显示效果
6. 可继续添加更多文字，或撤销/重做
7. 点击「Save All」测试性导出到新文件，并重新打开输出 PDF 核对结果

### 绘制矩形

1. 进入工具箱 → 点击「矩形」
2. 打开 PDF 文件
3. 设置矩形参数：
   - 位置和大小（X, Y, 宽度, 高度）
   - 边框颜色和宽度
   - 是否填充及填充颜色
4. 点击「Add」加入历史
5. 在预览画布上拖拽可直接设定矩形区域

### 添加高亮

1. 进入工具箱 → 点击「高亮」
2. 打开 PDF 文件
3. 设置高亮参数：
   - 位置和大小
   - 颜色（默认黄色）
   - 透明度（0-1，默认 0.4）
4. 点击「Add」加入历史

### 操作历史

编辑工具底部会显示操作历史列表：
- 每条记录显示操作类型和目标页码
- 当前位置的操作会高亮显示
- 撤销后，被撤销的操作会变灰
- 可点击垃圾桶图标清空所有历史

## 10. 表格提取

表格提取功能可以自动检测 PDF 页面中的表格结构，并将其转换为可编辑的数据。

### 使用方法

1. 进入工具箱 → 点击「表格提取」
2. 打开包含表格的 PDF 文件
3. 工具会自动扫描所有页面并检测表格
4. 检测结果显示：
   - 找到的表格数量
   - 每个表格的置信度（百分比）
   - 表格尺寸（行数 × 列数）

### 浏览表格

- 如果检测到多个表格，使用下拉框切换
- 表格以可编辑的 HTML 表格显示
- 可以直接在表格中修改内容

### 导出表格

1. 选择导出格式：**CSV** / **TSV** / **Markdown**
2. 点击「Export」保存为文件
3. 或点击「Copy」复制到剪贴板

### 准确率说明

表格提取基于文本位置聚类算法：
- **适合**：排版规整、行列对齐的表格（如财务报表、成绩单）
- **不适合**：合并单元格、嵌套表格、手写内容
- 置信度 > 70% 通常表示提取结果较为准确
- 置信度 40%-70% 可能存在部分误差，建议人工核对
- 置信度 < 40% 建议不使用自动结果

## 11. 批量处理

批量处理功能可以对多个 PDF 文件同时执行相同的操作。

### 使用方法

1. 进入工具箱 → 点击「批量处理」
2. 选择要处理的文件：
   - 点击「选择文件」多选 PDF 文件
   - 或点击「选择文件夹」导入整个文件夹中的 PDF
3. 选择要执行的操作：
   - **压缩**：减小文件体积
   - **旋转**：按指定角度旋转所有页面
   - **PDF 转文本**：提取文字内容
   - **PDF 转图片**：导出为图片
4. 根据所选操作设置参数（如旋转角度、DPI 等）
5. 点击「开始处理」

### 处理进度

- 文件列表显示每个文件的处理状态
- 状态图标：等待中 / 处理中 / 已完成 / 失败
- 单个文件失败不会中断整个批次
- 全部完成后可以查看每个文件的结果

## 12. S3 云存储

PDF Seeker 支持连接任何 S3 兼容的对象存储服务，实现 PDF 文件的上传、下载和管理。

### 配置步骤

1. 点击侧边栏 →「设置」→「S3 兼容存储」
2. 填写连接信息：

| 配置项 | 说明 |
|--------|------|
| Endpoint | 存储服务地址 |
| Region | 区域（如 `us-east-1`） |
| Bucket | 存储桶名称 |
| 认证方式 | 选择密钥认证或环境变量 |
| Access Key | 访问密钥（密钥认证时填写） |
| Secret Key | 秘密密钥（密钥认证时填写） |
| 强制路径风格 | 部分存储服务需要开启 |
| 根前缀 | 可选，用于隔离存储空间 |

3. 点击「测试连接」验证配置是否正确
4. 测试通过后点击「保存」

### 使用云存储

1. 点击侧边栏 →「存储空间」
2. 浏览文件和文件夹
3. 支持的操作：
   - 双击文件夹进入
   - 点击面包屑路径导航
   - 上传本地文件
   - 下载云端文件
   - 创建新文件夹
   - 查看文件版本历史
   - 删除旧版本

> **隐私说明**：所有配置信息仅保存在本地，不会上传到任何服务器。上传/下载操作需要手动触发，不会自动同步。

## 15. 常见问题

### macOS 提示"已损坏"无法打开

这是 macOS 对未签名应用的 Gatekeeper 保护。打开终端执行：

```bash
xattr -c /Applications/PDF_Seeker.app
```

### 表格提取结果不准确

表格提取基于文本位置聚类算法，对以下情况效果较好：
- 由文本组成的规整表格
- 行列对齐、间距均匀

对以下情况效果有限：
- 扫描件（建议先使用 OCR 处理）
- 合并单元格
- 复杂嵌套表格
- 图片中的表格

### 编辑工具修改后原文件没有变化

编辑工具采用**非破坏性编辑**模式：
1. 所有编辑操作暂存在内存中
2. “Save All”会尝试生成新的 PDF 文件；请重新打开并核对输出
3. 原文件不会被修改

### 批量处理中某个文件失败了

批量处理采用串行模式，单个文件失败不会影响其他文件。处理完成后可以查看失败原因，单独对失败文件重新处理。

### S3 连接失败

请检查：
1. Endpoint 地址是否正确（注意协议 `https://` 或 `http://`）
2. Access Key 和 Secret Key 是否有效
3. Bucket 是否存在且有权限访问
4. 是否需要开启「强制路径风格」（MinIO、阿里云 OSS 等通常需要）
5. 网络连接是否正常

### 离线使用

PDF Seeker 的所有本地功能（查看、编辑、转换、提取）均可在离线状态下正常使用。仅 S3 云存储功能需要网络连接。
