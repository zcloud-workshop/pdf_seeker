# v0.4 长期目标实施计划

> 对应 `README.md` roadmap「长期（v1.0）」六项。本文档是本次实施的单一任务追踪来源，每完成一项勾选对应 checkbox。

## 背景与目标

v0.3（页面裁剪、批注、表单填写、覆盖式替换文本、加密/解密）已合并 main（`e5f9534`，PR #3）。v0.4 目标为 roadmap 全部六项长期功能：

1. 多标签页同时打开多个 PDF
2. PDF 书签管理
3. PDF 对比（Diff）——文本 diff + 并排视觉对比
4. 云端同步（S3 自动备份/恢复配置文件）
5. 插件系统——外部命令插件 v1
6. 自动更新（Tauri updater 插件，完整实施含签名密钥）

## 总体策略

- **分支**：`feat/v0.4-long-term-goals`，每功能一个 commit，完成后开 PR 合并 main（沿用 v0.2/v0.3 流程）。
- **验证标准**：`cd src-tauri && cargo test` 全绿；`npm run check` 不劣化存量基线（2 错误 5 警告，系 v0.3 之前已存在）；每功能在 `npm run tauri dev` 手动冒烟。
- **实施顺序**（按依赖排列）：存量修复（config 持久化三个 bug，云同步前置）→ 多标签（重构基础）→ 书签 → 对比（复用 PdfScroller）→ 云同步 → 插件 → 自动更新。
- **依赖注意**：crates.io 被拦截时手动编辑 Cargo.toml + rsproxy 镜像参数构建（既有绕行方案）。

## 关键技术决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 多标签状态 | `currentFilePath/currentFileName` 改为 **derived store**（tabs + activeTabId 派生） | Tools/Toolbar 等大量 `$currentFilePath` 读点零改动，最小化 3230 行 Tools.svelte 的风险 |
| 同文件多开 | **按路径去重**（已开则激活既有 tab） | Tools 就地编辑同一文件的两个 tab 会互相覆盖字节 |
| 书签写入 | lopdf 手工构建 /Outlines 树，标题非 ASCII 走 UTF-16BE + BOM | 沿用项目「lopdf 对象级手术」惯例；pdfjs 只做读取 |
| 对比算法 | 前端自实现行级 LCS diff（~50 行 TS，不引第三方依赖） | 离线安全、零供应链风险 |
| 插件 v1 形态 | manifest（JSON）注册外部 CLI 命令，占位符传参、无 shell 直传 | 边界清晰防注入；类似内置 Tesseract OCR 机制；JS 沙箱插件留待 v2 |
| 更新源 | GitHub Releases `latest.json`（tauri-action 已有 `includeUpdaterJson: true`） | 免自建更新服务器；需补签名密钥与 CI env |

## 第 0 步：存量修复（云同步前置条件） 

探索确认三个改动前即存在的 bug：

1. **config 状态始终为默认值**：`lib.rs` 用 `AppConfig::default()` 做 managed state，`config::init()` 加载的配置被丢弃。
2. **保存/读取路径不一致**：`update_config` 走 `save_config()` 写 `ProjectDirs` 路径，读取走 `app_config_dir()`，持久化配置永远读不回。
3. **RecentFilesState 从未 manage**：`recent.rs` 三命令运行时必失败（前端吞错，首页最近文件永远为空）。

**任务清单**：
- [ ] `lib.rs` setup 加载配置写回 managed Mutex
- [ ] `update_config` 改收 AppHandle，统一 `save_config_with_handle`；删除孤儿 `save_config()`
- [ ] 最近文件并入 `general.recent_files: Vec<String>` 持久化，删除 RecentFilesState；`recent_files_max` 生效；前端类型同步
- [ ] cargo test + 手动验证（重启后配置与最近文件保留）

## 功能 1：多标签页

**目标**：同时打开多个 PDF，标签栏切换，各 tab 保留滚动位置/缩放。

**技术方案**：
- stores：`Tab {id, path, name}`、`tabs`、`activeTabId`、`openTab/closeTab/activateTab`；`currentFilePath/currentFileName` 变 derived。
- `Viewer.svelte` 单文档逻辑抽为 `components/viewer/PdfScroller.svelte`（props: tab），Viewer `{#each $tabs}` 渲染、非激活 CSS 隐藏保活；`{#key $currentView}` 保留。
- 新 `TabBar.svelte`（Toolbar 下方，可滚动、关闭按钮、"+"、Cmd/Ctrl+W）。
- Toolbar/Home 改调 `openTab`；Tools 确认路径变化清空 undo 栈。

**任务清单**：
- [ ] stores 重构 + TabBar 组件 + App/Toolbar/Home 接线
- [ ] PdfScroller 抽取 + Viewer 多实例保活
- [ ] i18n + 手动冒烟（切 tab 位置保留、去重、关 tab）

## 功能 2：PDF 书签管理

**目标**：查看器侧栏展示书签树、点击跳页；管理模式增/删/改名/排序（上移下移、升降级）；写入真实 /Outlines，任意阅读器可见。

**技术方案**：
- 读取：pdfjs `getOutline()`（扩展 `pdfjs-dist.d.ts` 环境类型 + dest 解析页码）。
- 写入：`pdf_ops.rs` 新命令 `set_outline(input, output, items)`——lopdf 构建完整 /Outlines 树（/First /Last /Next /Prev /Parent /Count，/Dest `[pageRef /XYZ null null null]`），中文标题 UTF-16BE + BOM。
- UI：Viewer 左侧可折叠侧栏（书签树 + 编辑按钮组）；就地写入 + 单步撤销（内存快照 Cmd+Z）+ 写后重载。

**任务清单**：
- [ ] 后端 `set_outline` + 单测（结构断言、中文标题往返、dest 页码、空清空）
- [ ] 前端书签侧栏（查看 + 管理 + 撤销）
- [ ] i18n + README

- [ ] Compare 视图（选文件、双模式、同步滚动、diff 着色、汇总过滤）

## 功能 4：云端同步（S3 配置备份/恢复）

**目标**：配置文件（含最近文件）一键/自动备份到 S3，可查看备份信息并按版本恢复。

**技术方案**：
- `S3Config` 增 `auto_backup_config: bool`、`last_backup_at: Option<String>`（serde default）。
- 新命令：`sync_backup_config`（上传 `{root_prefix}/config-backup/config.toml` + `info.json`）、`sync_fetch_backup_info`、`sync_list_backup_versions`、`sync_restore_config(version_id?) -> AppConfig`（下载→校验→替换 managed state + 落盘，返回值驱动 Settings 刷新）。
- Settings 新「云同步」区；恢复前确认（覆盖本地含 S3 配置本身）。
- 单测覆盖纯逻辑（TOML 往返、key 拼装、info serde）；S3 路径 MinIO 手工验证。

**任务清单**：
- [ ] S3Config 字段扩展 + sync 命令 + 单测
- [ ] Settings 云同步区（开关、立即备份、版本列表恢复）

## 功能 5：插件系统（外部命令插件 v1）

**目标**：插件目录放 manifest，工具箱出现「插件」分区，把当前 PDF 传给外部 CLI 执行并展示/保存输出。

**技术方案**：
- 目录 `{app_config_dir}/plugins/<id>/plugin.json`：`{id, name, version, description, command, args[], output:{mode:"text"|"file", extension?}, timeout_secs?}`；占位符 `{input}/{output}/{dir}`。
- `commands/plugins.rs`：`list_plugins`（扫描+解析，非法跳过）、`run_plugin`（无 shell 直传参数、cwd=插件目录、spawn_blocking、超时 kill 默认 120s、返回 stdout/stderr/exit_code）。
- Tools 新「插件」分区：选目标文件（默认激活 tab PDF）、file 模式先选输出路径、loading、结果 stdout `<pre>` / shell-open、非零退出展示 stderr。
- `docs/plugin-example/` 跨平台示例 + `docs/plugins.md` 规范。

**任务清单**：
- [ ] 后端 manifest 解析/执行 + 单测（纯函数跨平台 + `/bin/echo` cfg(unix)）
- [ ] Tools 插件分区 UI
- [ ] 示例插件 + 文档 + i18n + README

## 功能 6：自动更新（Tauri updater）

**目标**：release 构建自动产出签名更新产物与 latest.json；应用内检查更新→下载安装→重启。

**技术方案**：
- 依赖：`tauri-plugin-updater`、`tauri-plugin-process`（Rust + npm 双侧；crates.io 拦截则手动编辑 + rsproxy）。
- `tauri.conf.json`：`createUpdaterArtifacts: true`、`plugins.updater.endpoints`（GitHub Releases latest.json）、`pubkey`、`windows.installMode: "passive"`。
- 密钥：本地 `tauri signer generate`（私钥 `~/.tauri/` 不入库）；GitHub Secrets 清单交由维护者添加。
- CI `release.yml`：构建步注入 `TAURI_SIGNING_PRIVATE_KEY(_PASSWORD)` env。
- 前端：Settings「自动检查更新」开关（`general.auto_update_check`）+「立即检查」；启动 PROD 才检查；check → dialog → downloadAndInstall（进度）→ relaunch。
- capabilities 加 `updater:default`、`process:allow-restart`。

**任务清单**：
- [ ] 依赖接入 + tauri.conf.json + capabilities + lib.rs 注册
- [ ] 签名密钥生成 + pubkey 填入 + CI env + Secrets 清单
- [ ] Settings 更新 UI + 启动检查 + i18n + README
- [ ] 本地 `tauri build` 验证 updater 产物（.tar.gz/.sig/latest.json）
