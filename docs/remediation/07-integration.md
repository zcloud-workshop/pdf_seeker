## 7. 交付与 Git

子任务开工时从已满足前置条件的最新主分支创建独立分支, 例如 07-A:

```sh
git fetch origin
git switch -c codex/remediation-07-a origin/main
```

逐文件提交并对完整变更验证后:

```sh
git push -u origin codex/remediation-07-a
```

07-B/C/D/E 使用各自同样格式的唯一分支, 不复用已合并的 07-A 分支. 各 PR 同步、冲突处理遵循总规则. 每份证据保存为 `docs/remediation/evidence/07-子任务.md`, 记录修复文件、触发样本、命令和结果、独立阅读器/平台结果、残余限制及测试时 main SHA.

分配者最后汇总 R01-R30 的关闭状态. 未具备测试服务、签名环境或平台验证的项明确保留待验收, 不为了完成整个表格提前勾选.
