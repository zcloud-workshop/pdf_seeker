# 02 PDF 后端正确性

状态: 已实施, PR #10 已合并; 证据见 [evidence/02-pdf-backend.md](evidence/02-pdf-backend.md). 先读 [分工与合并规则](README.md). 主要对应 R02-R06、R09-R11、R13、R24、R28; R08 先准备样本, 协议改动交 07.

## 1. 写入范围与独立合并条件

独占 `src-tauri/src/commands/pdf_ops.rs` 和 `security.rs`. 两个文件的相关算法应由同一负责人维护, 避免 Contents、资源、保存函数各自提取出不兼容实现. 新内部模块放入各自同名子目录, 从已拥有的文件声明, 不改公共 `commands/mod.rs` 或 `lib.rs` 注册表. Cargo 依赖需求交 01 先落地.

保留第一轮已有 IPC 命令、请求和响应契约, 用旧前端完成冒烟. 新原子恢复命令、版本 token、几何语义、书签完整目标、有序 OCR 请求/逐页结果由 07 做同 PR 前后端接入. 不以模拟的新调用方通过测试代替旧前端兼容.

- [ ] R02: 在小型共用函数中规范化 Contents 的单流、直接数组和间接数组, 支持解引用并输出扁平流引用. 更新文字、水印、签名、矩形、高亮、覆盖替换所有追加调用点.
- [ ] R03: RGB/alpha 像素与 Filter 一致, 实际压缩后才声明 FlateDecode. 灰度 JPEG 不一律声明 DeviceRGB, 检查透明签名 SMask.
- [ ] R04: 重编号后读取实际页序, 修正多层页树插入; 完整维护 Parent/Kids/Count 和继承属性. 重排必须完整、唯一、无越界, 校验失败不写文件.
- [ ] R05: 解析继承、直接、间接和共享 Resources, 保留旧资源, 对目标页复制后修改, 分配不冲突的字体/图像/graphics state 名称. 不仅修签名 XObject 一处.
- [ ] R06 后端: 统一 PDF 输出为同目录临时文件、必要刷盘、可读性检查及平台适配替换. 枚举 `doc.save`、文件写入和 security 路径, 覆盖所有后端 PDF 写入. 同文件的读改写需在同一互斥范围, 不能只锁最终 save. 注入写入/替换失败保护原文件. 前端 `writeFile` 撤销仍绕过此边界, 明确留给 07-A, 此时不能关闭整个 R06.
- [ ] R09: 区分 PDF 元数据字符串编码和可见文字字体/字形映射, 复用既有书签文本编码函数. 处理中文批注、字段名/值; 新绘制块 q/Q 配对. 页面中文需要字体方案时核验许可、字体来源和依赖, 不把 UTF-16 编码当作字体支持.
- [ ] R10 后端: 统一 AcroForm 读写能力, 处理内联/间接字典、字段类型继承、真实 checkbox 导出值、radio widgets 和外观. 在旧请求能表达的范围内完成修复; 新增能力字段与前端联动放 07-C, 不先返回前端无法消费的新结构.
- [ ] R11 后端: 修正后代 Count. 现有 `OutlineItemInput { title, page, children }` 无法表达外部目标和无目标分组, 第一轮检测不可无损改写的原目录并明确拒绝, 不再静默抹掉信息. 完整目标协议在 07-C 落地.
- [ ] R13 后端: 在旧 `imageDir`/`language` 请求下隔离本任务临时数据, 只读取该任务目录, 不把其他任务的 PNG 纳入. 明确目录所有权, 不递归清理调用方任意目录. 逐页映射、取消和渲染前失败清理需要 07-D 联调, 第一轮不把全篇阈值或页失败吞掉视为已修复.

- [ ] R28 后端: 拆分/导出文件冲突在写之前发现, 未选择覆盖策略就拒绝覆盖. 全失败返回错误. 旧结果无法表达部分失败时先明确报错, 结构化报告交 07-D. 后端页范围也严格验证, 不允许前端绕过后造成大范围展开.
- [ ] R08: 准备非零原点、浮点尺寸、继承 Rotate/CropBox 样本并记录每个命令当前坐标语义. 第一轮不单方面改变坐标单位、原点或旋转约定, 等 07-B 一起接通.

正确性回归通过后, 才按 Contents/资源/页树/保存等已有责任提取小模块. 不在一个提交组里同时重写算法与全部目录结构.

## 3. 验收

| 样本/场景 | 必须证明 |
| --- | --- |
| 三类 Contents, 连续三次混合编辑 | 原文和每次新增内容可提取、可独立渲染 |
| RGBA PNG、灰度 JPEG、已有图片的 PDF | 颜色/透明度正确, 原图不丢 |
| 逆序 ID、非零 generation、两/三层页树 | 合并及首中尾插入页序正确, Parent/Kids/Count 一致 |
| 重复/缺失/越界页序 | 拒绝且文件字节不变 |
| 共享/继承资源 | 修改页正确, 非目标页和旧内容不变 |
| 磁盘写入/替换失败、并发编辑 | 原文件不被截断, 后端读改写串行, 可重试 |
| 中文与真实 Widget/AP | 值、字形和可见外观跨阅读器一致 |
| 加密外部样本和失败路径 | 错误密码与不支持算法可区分, 不留临时明文 |

```sh
cargo test --manifest-path src-tauri/Cargo.toml --locked
```

另外用应用内 pdfjs 和至少一个独立解析/渲染实现验证, 加密样本至少一份来自独立实现. 提交测试命令、样本说明、渲染证据; 不仅断言文件存在或用 lopdf 自产自读. Windows 原子替换未测时如实标为未验收.
