# 03 文档会话与编辑界面

状态: 已实施(分支 `codex/remediation-03`,基线 `cd01590`),证据见 [evidence/03-document-ui.md](evidence/03-document-ui.md). 先读 [分工与合并规则](README.md). 主要对应 R06/R07、R10-R15、R26 的 pdfjs 类型、R27 和 R28 的工具界面. R08 在 07-B 联调.

## 1. 写入范围与兼容边界

独占 Tools、Viewer、PdfScroller、stores、TabBar、Tooltip、pdf-engine、pdfjs 类型声明. 新模块放 `src/lib/document/` 和 `src/lib/components/tools/`, 测试放 `tests/remediation-03/`. 不修改 Compare、Toolbar、Home、Input、字典、Rust 或公共依赖文件.

先检索现有 `openTab`/`closeTab`、当前文件派生 store、编辑历史和所有 `writeFile` 引用. `stores/index.ts` 现有导出和 `Tab` 既有结构保持兼容, 新会话从现有入口接入; 调用方不应被迫等待本包以外的修改. `PdfScroller` 保留 props 和 `getScrollContainer()`, 不把 inactive 解释为不能渲染.

## 3. 验收

| 操作 | 必须证明 |
| --- | --- |
| A/B 切换、关闭活动标签、延迟任务返回 | A 结果不能应用到 B, 过期回调不污染 UI |
| Tools -> Viewer -> Tools | 同文件历史、页码、缩放保留 |
| 撤销/重做遇到写入失败或忙碌 | 历史不提前弹出, 同文件不并发写 |
| 替换面板与输入框 Cmd+Z | 前者可撤销 PDF, 后者仅撤销文字 |
| 书签保存后刷新 | 历史仍可用, 复杂目录不能被静默删除 |
| 快速翻页/参数变化 20 次 | 最终预览正确, 无未处理异步异常 |
| 非法页范围与 1000 页扫描 PDF | 输入即时拒绝; 首屏、内存按记录的预算验收 |
| 表格第 3 页与数值 0 | 操作目标及保存参数准确 |

按 01 已落地的 nvm/pnpm 约束执行 check、build 和前端行为测试. 01 未合并时记录本地实际环境, 不为本包另造锁文件/测试 runner. 本包测试合并时必须有实际执行入口, 若入口尚未落地则先交接给 01 并等待该前置 PR. GUI 验证覆盖旧后端及合入后的组合, 性能阈值先记录固定机器基线再决定.
